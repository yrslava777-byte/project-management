# Управление программными проектами

В Битрикс24 вы выполняете практику, а в этом репозитории сохраняете отчёт со ссылками и своими скриншотами. Код магазина писать не нужно.

| Практика | Задание и сдача | Тексты для Битрикс24 |
| --- | --- | --- |
| Проект, задача и результат | [lesson_02](lesson_02/README.md) | [texts.md](lesson_02/texts.md) |
| Уточняем требования | [lesson_03](lesson_03/README.md) | [texts.md](lesson_03/texts.md) |

Номера папок совпадают с номерами тем курса. Обе практики выполняются в одном проекте «СЕВЕР».

## Создайте свой репозиторий

На странице шаблона нажмите **Use this template → Create a new repository**. Укажите имя `project-management` и свою учётную запись в **Owner**. Видимость и доступ преподавателя согласуйте до загрузки снимков: файлы публичного репозитория доступны всем.

Если свой репозиторий уже создан, продолжайте в нём. Добавьте недостающую папку практики и обновлённые файлы `checks/` и `.github/workflows/` из шаблона. Существующие отчёты и снимки сохраняйте.

## Сдача через сайт GitHub

1. Выполните задание в Битрикс24. Состав снимков указан в папке практики.
2. В своём репозитории откройте её папку `screenshots`. Через **Add file → Upload files** загрузите PNG и нажмите **Commit changes**.
3. Откройте `report.md` той же практики. Нажмите **Edit this file**, замените `[[...]]` своими ссылками и сохраните через **Commit changes**. Готовые ссылки на снимки оставьте.
4. Откройте **Actions** и последний запуск проверки. Дождитесь результата задания `lesson_02` или `lesson_03` — в зависимости от сдаваемой практики. При ошибке откройте журнал, исправьте названный файл и сохраните новый коммит.
5. Отправьте преподавателю ссылку на папку выполненной практики и её успешную проверку.

Коммит — сохранённая версия файлов репозитория. GitHub Actions запускает автоматическую проверку после сохранения. Проверяется комплектность: ссылки, наличие снимков и формат PNG. Содержание принимает преподаватель. Незаполненная практика сообщает об ошибке независимо от выполненной.

## Скриншоты

Используйте свои снимки с демонстрационными данными, без блюра и закрасок. Названия задач, поля, кнопки и текст должны читаться полностью. Если запись не помещается, добавьте продолжение и ссылку на него в отчёт. Кадры из урока не заменяют вашу работу.

Не загружайте пароли, коды входа, токены, платёжные сведения и постороннюю переписку. Если в окне есть такие данные, переснимите его в безопасном окружении. Ссылки закрытого портала могут требовать входа; не открывайте проект для всех ради проверки.

PNG: исходное разрешение, от 640 × 360 до 12000 × 12000 пикселей, до 10 МиБ на файл.

## Проверка на своём компьютере

Для работы через сайт установка Python не нужна. Локально, с Python 3.12 или новее:

```sh
python3 checks/check_submission.py --lesson 02
python3 checks/check_submission.py --lesson 03
```
