# Практика 2. Организация работы в Битрикс24

**Ярослава Медведева**

В этой работе я оформила проект учебного интернет-магазина «СЕВЕР» и описала, что должно произойти, если двое покупателей одновременно пытаются заказать последний рюкзак. В проекте зафиксировала цель и границы первого выпуска, а в карточке задачи — условие, ожидаемый результат, критерий проверки, исполнителя и срок.

В чате первой задачи опубликовала правила резервирования и проверила два случая. При одновременной покупке резерв получает один покупатель, а второй видит сообщение о недоступности. Если первый покупатель не оплачивает заказ за 15 минут, резерв снимается и рюкзак снова можно заказать. После этого первая задача отмечена как завершённая.

Для продолжения работы поставлены ещё две задачи: описать состав карточки рюкзака и подготовить проверки правил резервирования.
