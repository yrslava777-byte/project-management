# Проект, задача и результат в Битрикс24

Создайте проект магазина «СЕВЕР», три задачи и результат первой задачи. Пошаговые действия и кадры — [в практике](https://maximbytecamp.github.io/algorthimization_course_vvodnoe/upravlenie-programmnymi-proektami/lessons/02-bitrix24/), тексты для полей — в [texts.md](texts.md).

Назначьте задачи себе и укажите актуальные сроки. Срок подготовки проверок должен быть не раньше срока подготовки правил. Первую задачу начните, опубликуйте результат, проверьте его по двум примерам и завершите. Задачи о карточке товара и проверках оставьте незавершёнными, пока их результаты не готовы.

## Что сдать

Заполните пять ссылок в [report.md](report.md). Адрес проекта скопируйте из открытого проекта, адрес каждой задачи — из её карточки. Ссылки должны вести на ваши записи.

В `screenshots/` загрузите семь PNG:

| Файл | Что должно быть видно |
| --- | --- |
| `01-project.png` | Сохранённый проект: название, цель, границы первого выпуска. |
| `02-task-reservation.png` | Первая задача до завершения: название, полное условие, результат, критерий, исполнитель, срок и проект. |
| `03-result.png` | Опубликованный результат: три правила, резерв 15 минут и примеры А и Б. |
| `04-review.png` | Отправленная самопроверка двух примеров или отзыв другого участника. |
| `05-completed.png` | Название первой задачи и статус «Завершена». |
| `06-task-product-card.png` | Задача о карточке рюкзака: условия, результат, критерий, исполнитель, срок, проект и статус. |
| `07-task-checks.png` | Задача о проверках последнего товара: три ситуации, формат проверки, исполнитель, срок, проект и статус. |

Сохраняйте название задачи в кадре. Если длинный текст не помещается, добавьте снимок-продолжение и ссылку на него в отчёт. Порядок загрузки и проверки — в [общей инструкции](../README.md#сдача-через-сайт-github).
