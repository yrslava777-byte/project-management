Копируйте блоки в соответствующие поля своего портала. Названия, цель, условия и правила резерва уже заданы. Самостоятельно выберите **свою учётную запись исполнителя**, **актуальные сроки** и перенесите **свои ссылки** в отчёт. Даты и адреса из кадров преподавателя не копируйте.

## Проект

**Название:**

```text
СЕВЕР — учебный запуск интернет-магазина
```

**Цель проекта:**

```text
Покупатель выбирает рюкзак, видит условия доставки и оплаты и оформляет заказ. Менеджер принимает заказ, а склад отгружает товар без двойного резервирования.
```

**Описание:**

```text
Первый выпуск: каталог, карточка рюкзака, оформление заказа и резервирование последнего товара. Личный кабинет, отзывы, программа лояльности и мобильное приложение — вне первого выпуска.
```

Создайте закрытый проект. Не приглашайте случайных людей ради задания. После сохранения снимите название, цель и описание для `01-project.png`.

## Задача 1 — правила резервирования

**Название:**

```text
Описать правила резервирования последнего товара
```

**Описание:**

```text
На складе один рюкзак. Два покупателя оформляют заказ.

Подготовьте описание правил:
1. В какой момент товар резервируется.
2. Когда резерв снимается.
3. Что увидит второй покупатель, если товар уже зарезервирован.

Результат: текст с правилами и двумя примерами оформления заказа.
Критерий проверки: по тексту однозначно определяется результат для обоих покупателей.
```

Исполнитель — ваша учётная запись; крайний срок — согласованная дата и время. Проверьте связь с проектом «СЕВЕР». Сохраните задачу и снимите условия, исполнителя, срок и проект для `02-task-reservation.png`. Нажмите «Начать» и подготовьте результат.

### Результат первой задачи

Копирование образца разрешено, но перед завершением нужно разобраться в обоих примерах и проверить их по критерию задачи. Этот текст описывает требования, а не результат тестирования работающего магазина. Перенесите его сообщением в чат первой задачи, не вместо исходного описания.

```text
Правила резервирования — версия 1.

1. При подтверждении оформления система проверяет остаток и создаёт резерв одной неделимой операцией. Первый успешный запрос получает последний рюкзак.
2. Резерв действует 15 минут. После подтверждения оплаты товар закреплён за заказом. При отмене или истечении срока без оплаты резерв снимается.
3. Второму покупателю показывается «Товар временно недоступен». Заказ на этот рюкзак не подтверждается.

Пример А: два одновременных запроса при остатке 1 — один резерв, второму отказ.
Пример Б: первый покупатель не оплатил за 15 минут — резерв снят, второй может оформить заказ.
```

Найдите отправленное сообщение и снимите `03-result.png`. Если текст длинный, добавьте кадр-продолжение; не заменяйте его снимком неотправленного сообщения.

## Задача 2 — карточка товара


**Название:**

```text
Описать состав карточки рюкзака
```

**Описание:**

```text
Для первого выпуска магазина «СЕВЕР» нужно определить состав карточки рюкзака.

Укажите обязательные данные:
1. Название.
2. Цена.
3. Изображение.
4. Вариант цвета.
5. Доступный остаток.

Результат: список данных о товаре с примером заполнения одной карточки рюкзака.
Критерий проверки: по описанию можно составить карточку одного товара без уточнения обязательных полей.
```

Выберите себя исполнителем, задайте актуальный срок, сохраните в том же проекте. Снимите `06-task-product-card.png`. Сам список с примером заполнения — будущий результат этой задачи; здесь он намеренно не написан. Пока результата нет, не завершайте задачу.

## Задача 3 — проверки последнего товара

**Название:**

```text
Подготовить проверки последнего товара
```

**Описание:**

```text
Подготовьте три проверки по правилам резервирования — версия 1, сохранённым в задаче «Описать правила резервирования последнего товара» этого проекта. Резерв действует 15 минут.

Проверьте ситуации:
1. Два покупателя одновременно оформляют последний рюкзак.
2. Срок резерва истёк, оплата не подтверждена.
3. Оплата подтверждена в пределах срока резерва.

Для каждой проверки укажите исходные данные, действие и ожидаемый результат.

Результат: три проверки по правилам резервирования в указанном формате.
Критерий проверки: проверены одновременная покупка, истечение резерва и подтверждение оплаты в пределах срока; ожидаемые результаты не противоречат правилам резервирования.
```

Выберите себя исполнителем. Срок — не раньше срока подготовки правил. Сохраните задачу в проекте и снимите `07-task-checks.png`. Сами три проверки — будущий результат, его нужно будет подготовить самостоятельно. Для этой сдачи достаточно поставить задачу; без результата не завершайте её.

## Проверка результата

Выберите **один** вариант. Нельзя копировать подтверждение до проверки или писать от имени другого человека.

### Индивидуальная работа

Прочитайте результат первой задачи, проверьте оба примера по её критерию. Если обнаружили противоречие — сначала исправьте результат. Только затем отправьте в чат первой задачи:

```text
Самопроверка результата «Правила резервирования — версия 1».

Пример А: при остатке 1 два одновременных запроса дают один резерв; второму покупателю сообщается о временной недоступности.
Пример Б: если оплаты нет 15 минут, резерв снимается; второй покупатель может оформить заказ.

Оба примера соответствуют описанным правилам. Условие задачи выполнено: для обоих покупателей результат определяется однозначно.
```

Снимите отправленную отметку для `04-review.png`.

### Работа с другим участником

Если участник уже имеет согласованный доступ к проекту, попросите проверить результат. Не создавайте фиктивный аккаунт и не приглашайте человека без договорённости. Вы можете отправить просьбу:

```text
Пожалуйста, проверьте результат «Правила резервирования — версия 1» по критерию задачи: однозначно ли определён результат для обоих покупателей в примерах А и Б? Оставьте подтверждение или конкретное замечание в чате этой задачи.
```

**Ответ участник формулирует самостоятельно** после чтения результата. Снимите настоящий ответ для `04-review.png`. Если есть замечания, устраните их и сохраните подтверждение исправления дополнительным кадром.

После проверки завершите первую задачу. Вернитесь в список проекта, снимите фильтр «В работе», найдите задачу и откройте её. Снимите название и статус «Завершена» для `05-completed.png`. Затем заполните [отчёт](report.md).
