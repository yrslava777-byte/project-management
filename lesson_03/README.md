# Уточняем требования в Битрикс24

Продолжите задачу «Подготовить проверки последнего товара» из первой практики. Новый проект и копия задачи не нужны. Пошаговые действия и кадры — [в практике](https://maximbytecamp.github.io/algorthimization_course_vvodnoe/upravlenie-programmnymi-proektami/lessons/03-trebovaniya/).

Сначала отправьте вопросы и условия примера в чат задачи. Затем сохраните требования R1–R5 версии 1 в описании и опубликуйте проверки P1–P5. После сообщения об изменении срока с 15 до 20 минут обновите R3 и связанные проверки. Полные тексты расположены в [texts.md](texts.md) в порядке действий.

В этой практике вы готовите требования и сценарии для будущих проверок магазина. В итоговом сообщении укажите, что проверили в тексте; задачу не завершайте до проверки преподавателем.

## Что сдать

В [report.md](report.md) укажите ссылки на свой репозиторий, проект и задачу. В `screenshots/` загрузите восемь PNG:

| Файл | Что должно быть видно |
| --- | --- |
| `01-questions.png` | Опубликованные четыре вопроса в чате задачи. |
| `02-answers.png` | Опубликованные согласованные условия: резерв 15 минут и границы работы. |
| `03-requirements-v1.png` | Сохранённое описание версии 1: результат работы, R1–R5, границы и условия готовности текста. Снимите до изменения срока. |
| `04-checks-v1.png` | Опубликованные P1–P5 версии 1: требования, исходное состояние, действие и ожидаемый результат. |
| `05-change.png` | Сообщение об изменении срока с 15 до 20 минут. |
| `06-requirements-v2.png` | Сохранённое описание версии 2: в R3 указан срок 20 минут. |
| `07-checks-v2.png` | Полные P1–P5 версии 2; в P3 и P5 отражён новый срок. |
| `08-summary.png` | Итоговое сообщение после самопроверки и название задачи. |

Снимайте версии по ходу работы: после замены описания версия 1 уже не будет текущей. В кадре сохраняйте название задачи. Для длинных записей добавьте снимки-продолжения и ссылки на них в отчёт. Порядок загрузки и проверки — в [общей инструкции](../README.md#сдача-через-сайт-github).
